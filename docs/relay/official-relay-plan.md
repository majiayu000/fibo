# 官方中继怎么开放

## 要定的事

官方中继要不要给没有自建中继的人用。看每月花费、滥用事件数、新用户里用手机远程的比例。

- 预算：每月 100 元以内（用户 11-08 定）。
- 放弃条件：花费超过预算，或出现处理不了的滥用，就退回邀请制或重新关上。

## 现在（11-08）

- 中继开着注册密钥，只有带密钥的电脑能挂上来；手机只能连和它配过对的电脑，内容端到端加密。
- 服务器是腾讯云上海的轻量应用服务器，套餐含流量包。11-04 到 11-08 一个人用，中继进出共约 300 MB，折合每月约 2 GB。
- 手机把中继地址存在每条配对里（`mobile/src/remote/link.ts`），中继换地址后旧配对不会跟过去，要重新配对。

## 第 1 步：邀请制

- 中继：一把共用密钥改成密钥清单，每人一把，带名字和额度，可单独吊销，改清单不用重启。
- 按密钥限每月流量和同时在线的电脑数。
- App：设置里「使用官方中继」，填邀请码。
- 发给 10–20 人，跑 2–4 周。成本在预算内、没有滥用，再进第 2 步。

## 第 2 步：公开

- App 第一次打开时自动领一把低额度密钥，按 IP 限领取频率，必要时加 GitHub 登录。
- 写清中继能看到什么（IP、连接时间、流量大小）、看不到什么（内容）。
- 腾讯云设带宽或流量上限，防账单失控；用户多了再考虑国内外各一台。

不做：把共用密钥写进 App（等于完全开放，安装包里一扒就有）。
