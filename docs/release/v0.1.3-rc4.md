### 小毛病（不阻断）

1. `fibo events` 每一轮重复发 4–6 次 started，done 基本每轮一次（RC3 小毛病 3 仍在）。另外还有三种多出来的 done，手机推送或通知插件可能因此重复提醒（推断，没验）：

   - OpenCode 接着做的终端一对上，就给新终端补发一条 done，detail 是上一轮的回复；
   - Codex 空闲窗格闪成在跑时，多出一组 done/started/done。
2. 关掉 OpenCode 终端时，events 先发一条没有 detail 的 error，再发 terminal_exited，本轮 4 次都这样（RC3 小毛病 5 仍在）。宿主被杀再起后，events 首屏给每个会话一条没有 detail 的 error：Claude `rc.hostrestart`、Codex `rm.twin` 重启、兼容线冷回退都看到了。

4. 接着做还没对上对话时，send 被拒的提示是「原对话已离开这个终端…」，其实是还没对上。不丢字。
5. Claude 计划菜单：卡片 waiting 里没有编号选项，手机解析不出一键按钮；画面上计划正文的「1.」会和菜单的「1. Yes」撞号。Claude 计划菜单和 Codex 的 request_user_input 提问框，读屏规则都没认出，状态来自 hook 或 OSC 7501，所以照样能用（RC3 小毛病 8 仍在）。
