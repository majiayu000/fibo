2026-11-02 · 六张同为 1440×788：Keepline 实拍、同类终端工具 实拍（同是 GPUI 原生 App）、重做 v1、参照 同类终端工具 的 v2，以及参照五家同类产品的 v3（主界面和看改动两张）

v3 加了什么（对应同类产品对照里的 1–6）

① Agent 图标标签、左栏行、窗格标题、底栏额度都用 Agent 图标，不再写「claude」两个字。
② 第二行写它在干什么「要你处理」和「在跑」的行多一行：问你什么、停在哪、正在跑什么命令。停着的仍是一行，省地方。左栏放宽到 264。
③ git 信息空间行写分支和 ↑↓；会话第二行写这一轮的 +增 −删。
④ 看改动页「等你验收」时窗格里多一条「这一轮改了 3 个文件 · 验收标准 1/2 · 看改动」。点开是单独一个标签：文件、diff、右边是验收标准勾选和批注，底部「发回 Claude Code」。退回和标记完成都能在这页点。
⑤ 额度按家分开底栏直接写 Claude 和 Codex 两家的 5h 和周，带小条；第三家收进「+1 ▴」。
⑥ 等你的窗格亮一圈分屏时等你回答的窗格描一圈橙色、标题栏浅橙；当前聚焦的窗格顶边一条深线（沿用 79cb070d 的做法）。左栏对应行有未读数字。

从 同类终端工具 借的六处

① 每个会话带 Agent 自己的图标同类终端工具 在标签、左栏行、窗格标题上都放 Agent 的小图标（Claude Code 是橙色像素小怪，Codex 是蓝色圆标）。一眼分清是谁在干活，比写「claude」两个字快。
→ v2 标签、左栏、窗格标题、额度按钮都换成 Agent 图标；普通终端用灰色终端图标。
② 窗格标题 = 谁 + 在哪同类终端工具 的窗格标题只有「图标 Claude Code ~/路径」，不重复会话标题。
→ v2 窗格标题写 Agent 名和目录，状态和「标记完成」放右边；会话标题只留在标签和左栏。
③ 左栏上下两块：空间在上，会话在下空间是彩色字母方块，右边跟分支和 ↑↓；会话按 Done / Working / Idle 分组带计数，钉在左栏下半。
→ v2 空间行加分支和领先落后数；会话按「要你处理 / 在跑 / 停着」分组。空间方块保留 Keepline 的渐变色。
④ 会话行写「空间 · 标题」，状态是最右一个符号同类终端工具 不写「等你回答」「在跑」这些字，最右一列只放一个符号：蓝点、转圈、空心圈。
→ v2 用 Keepline 自己的状态色：橙点＝等你回答，绿空心圈＝等你验收，黄转圈＝在跑，灰 ✓＝做完了，灰空心＝停着。分组标题已经说了是什么状态，所以行里不再写字。
⑤ 标签只在当前那个显示 ×，别的显示状态同类终端工具 的未读标签带一个小蓝点，正在干活的标签转圈。
→ v2 当前标签显示 ×，其他标签在名字后面放状态符号，不再给每个标签都加圆点。
⑥ 底栏只有两件事同类终端工具 底栏左边是「This computer · 12 agents」，右边是「⌘⇧P commands」。
→ v2 底栏左边是「本机 · 11 个会话」，右边是额度、诊断、⌘P；设置和「连接手机或其他电脑」挪到左栏底部，和 同类终端工具 的 Settings / Add machine 一样。

没照搬的

窗格做成圆角卡片、底色发灰同类终端工具 的窗格是灰底上的白卡片，聚焦时描蓝边。Keepline 11-02 刚定了「正文一整块白、窗格不做卡片」（79cb070d），所以 v2 没跟。
只用蓝一种状态色同类终端工具 的状态只有蓝点和灰圈。Keepline 已经定了黄 / 绿 / 灰三档，再加上「等你回答」的橙，信息更多，所以保留了。
Keepline 独有的「要你处理」和「标记完成」同类终端工具 没有验收这一步，这是 Keepline 的核心，v2 里保留成右上角按钮和窗格里唯一的实心按钮。
