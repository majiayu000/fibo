# 手机聊天里的电脑文件链接优先预览

## Context

用户点蓝色的「手机解锁设计稿」，预期在手机里打开文档。现有 Markdown 渲染器把网页地址和电脑路径都涂成链接色。前者交给系统打开，后者复制到剪贴板。要验证的是点文件名能读到对应电脑上的文档，离线或不可读时能看清原因。若方案扩大配对角色的文件访问范围，或会读到会话项目目录外的文件，则不采用。

## Decision

待验证。手机点击 `.md` 或 `.txt` 文件时，在 App 内打开只读预览。Markdown 沿用聊天渲染器，纯文本直接显示。预览提供「复制电脑路径」。电脑离线、版本尚未支持、文件找不到或不可读时，用提示和明确的「复制电脑路径」动作回应。普通网页链接沿用系统打开方式。

## Implementation Plan

手机和对话所属的那台电脑通信。现有 `read` 读终端画面，`diff` 提供 Git 改动，读取完整文档需要一个范围更小的接口。首版只允许已有「完全控制」配对读取会话项目目录下的 Markdown 或纯文本文件。由电脑确定会话目录、解析实际文件位置并限制读取大小。

与手机解锁宽限拆为两个 PR。文件预览改变手机聊天、电脑端接口和文件权限边界。解锁宽限改变手机前后台和远程授权体验。现有 #633 处理验证方式与自动弹窗，继续独立走查。

## Verification

在真手机点本对话里的设计稿，看到电脑上该文件的正文，返回后仍在原对话位置。核对普通网页、旧电脑端、离线、配对权限不足，以及指向项目之外的路径或符号链接。文件内容未返回时，用户仍能明确选择复制路径。
