# 第一版图标用系泊环，信号黄加墨色

## 背景

托盘还是改名前的文字 K，Dock 用的水墨缺口环在 macOS 26 上会被缩小并套浅色底板。这件事前后比较了约 200 张方案，见 `docs/icon-redesign/gallery/index.html`。

## 决定

用户选定“系泊环”的信号黄加墨色作为第一版：偏心的 C 形环，缺口处一枚圆角方桩。这个方案是 Antigravity 画的。Dock、标题栏和托盘同形，默认外观换成它。设置里可在系泊环、二次元、吉祥物三个之间切换，水墨拿掉了，保存过水墨的会回到系泊环。

- 托盘是模板图，右边只跟数字；连不上后台时方桩消失。
- 打包走 `assets/Mooring.icon` 经 actool 编译，`.icns` 只给旧系统。

## 否掉的

- 继续用文字 K：改名后对不上。
- 只换 `.icns`：macOS 26 上还会被套底板。

## 已知风险

托盘的缺口环可能被看成“加载中”的转圈，第一轮类似的单色版曾因此被否。是用户看过后仍然选的，真实菜单栏里要再看。
