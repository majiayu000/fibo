# 在先不管的空间里开始做事，整个空间就接着管

状态：采用（2026-11-07，用户选 C）

## 背景

先不管是一层遮罩。用户的本来场景是「下周接着聊」：如果回来直接开聊、忘了点「接着管」，切走后 Agent 提问不会提醒，正好踩中放弃条件里的「漏事」。机器级「先不管这台」的规则是打字也不接着管，空间不能照抄。

## 决定

打字、粘贴、回答审批、新开工作，以及手机在它的目录里打开，都让整个空间接着管。

只是看不算：展开、点开、切标签、滚动、鼠标上报、焦点上报。恢复原有的东西也不算：窗格显示出来就会自动恢复被中断的会话，这一步不是用户要开工。Agent 和脚本的动作不算。

## 否掉的方案

- A 什么都不改变状态：规则最简单，但会漏事。
- B 只有新开才回来：继续聊旧会话仍会漏，而这正是主要场景。
- 只让单个会话回来：多出第三个状态。

## 后果

回一句话也会让整个空间回来，想继续放着要再点一次先不管。这个代价看得见，漏事看不见。
