侧栏：会话下面挂子代理

Claude Code 每开一个子代理会写 <会话>/subagents/agent-*.meta.json（名字、类型、前台/后台、跑完写 finished）。三个方向都基于同一份数据，只是摆放不同。可以点有箭头的会话行来展开或收起。

要定的事：子代理放在侧栏哪里、什么时候展开、跑完后留多久。放弃条件：如果五个在跑的会话各开三四个子代理时侧栏超过一屏，或子代理行比会话行还显眼，就退回只显示计数的「后台仍有子 Agent N 个」。

现在

截自你的截图。有子代理的会话看不出来，只有回合结束后，第二行才会写「后台仍有…」。

A · 树枝常开

只要有子代理在跑，就在父会话下面直接展开 ├ └；全部跑完后自动收起。一眼就能看全，但会话多、子代理多的时候侧栏会很长。

B · 摘要行，点开成树 推荐

第二行写「子代理 ●●●○ 3 在跑」，默认收起；你当前所在的会话自动展开。每个会话的高度不变，进度一眼能看到，点开才看名字。

C · 行尾计数

行尾时间旁边加一个「⑂3」，只有当前会话展开。最安静，但没选中的会话只能看到数字，看不出跑了多少、完成了多少。

子代理行的几种状态（以 B 展开后为例）

规则

情形怎么显示
开了子代理看到新的 meta.json 就加一行，名字用 description。顺序按开启时间，先开的在上面。
在跑黄色缺口圈，时间从开启算起、跟着走秒，和会话行的「本轮 0:36」写法一样。
跑完灰色 ✓，名字变灰，时间定格为用时。保留到父会话这一轮结束；你发下一句话后，上一轮的子代理行就清掉。
失败或被停红色 ✕，保留到你看过这个会话为止。
前台子代理父会话被它挡住、在等它，名字后面标一个小「前台」。
父会话没了不显示。没写 finished 的 meta 只在父会话活着时才算在跑，避免旧会话留下的 3000 多个文件被当成在跑。
数量对不上Stop hook 报的子代理数比文件里在跑的少时，以 hook 为准，多出来的标为跑完。
超过 4 个展开时只列在跑的和最近 3 个，其余折成「还有 N 个已完成」。
点子代理行切到父会话的终端，不另开窗口。子代理的记录先不在侧栏里打开。
颜色子代理只用三种标记：在跑黄、跑完灰 ✓、失败红 ✕。不用会话的绿、橙，避免被当成「要你处理」。
