远程终端进标签：三个方向

现在另一台电脑的终端只能在偷看窗里看：一次一个、关掉就没了、不能和本机终端并排。下面三种做法都让它常驻在标签里；区别在能不能和本机终端混在一个标签、以及标签归谁管。侧栏怎么摆是另一份稿（sidebar-layouts.html），这里不动侧栏。

A 和本机终端一样，能混排分屏推荐

偷看窗标题栏加「放进标签」，或者从侧栏把远程会话拖进分屏。远程窗格和本机窗格并排，窗格标题和标签上带机器名小标。标签存在本机，退出重开还在；那台电脑断开时窗格显示「断开，重连中」。

部署 applezsh+
● 本机 · 库版本与 issue
› cargo test …
apple● 你好啊 · 等你验收
› 你好啊
● 你好！有什么需要帮忙的吗？
  • 好处：最像「另一台电脑的终端就在手边」；本机和远程对照着看最方便。
  • 代价：最大的一块。本机宿主要认得「远程终端」这种画面（只记位置，不管进程）；分屏、拖动、关标签都要处理远程的那一格。

B 每台电脑一个标签，照搬那边的布局

点侧栏里那台电脑的标题，打开一个专属标签「apple」，里面按 apple 自己的标签和分屏摆好它的终端。不能和本机窗格混在一起。

部署zshapple 你好啊 · w你好+
● 你好啊
› 你好啊
● w你好
› w你好
  • 好处：本机的标签和分屏代码几乎不用动；那台电脑上分好的屏这里直接就有。
  • 代价：不能一边本机一边远程地对照；那边改布局这边跟着变。

C 偷看窗可以「钉住」，钉住的单独成标签

偷看窗标题栏加「📌 钉成标签」，钉住后它变成一个只有这个远程终端的标签，可以开好几个；不能分屏。

部署apple 你好啊apple w你好+
● 你好啊 · 等你验收
› 你好啊
● 你好！有什么需要帮忙的吗？
  • 好处：改动最小、最快能用；一个远程终端一个标签，清楚。
  • 代价：不能并排；以后要分屏还得再做 A。

共用

地方做法
打字和偷看窗一样：开始打字就接管那边的终端，尺寸跟着本机窗格。
断开窗格变灰写「断开，重连中」，连回后自动接上，不用重新打开。
关掉关窗格只是不再在这里看；要停掉那边的终端用「关闭终端」，先确认。
