多台机器怎么进侧栏

要定的是侧栏用哪个方向，看板跟着走。放弃条件沿用 spec：两周内没真正连上远程机器用，就不做这轮界面。mac-mini 和它的会话是示意数据。

侧栏并排

现在

现在的问题 1. apple 的两个「等你验收」不在要你处理里，⌘J 也跳不到。 2. 远程行是另一种样式：实心点、状态词代替时间、没有空间。 3. 标题写 appledeMacBook-Pro.local，配置里的名字 apple 没用上。 4. 正在看 apple，右上角和底部仍写「本机」。

A 一张清单

A 推荐 所有机器进同一张清单，只有远程行多一个方块字母。 好：⌘J 和要你处理不用改概念，和看板方向 A 一致。 代价：机器和会话多时清单变长。

B 机器栏

B 左边一条机器栏，点一台，整个侧栏换成那台。 好：每台机器完整、互不打扰，机器多也不挤。 代价：要你处理被拆开，要靠徽标和 ⌘J 才看得全；行宽少 52。 适合：常年 4 台以上。

C 按机器折叠

C 每台机器一个可折叠的区，折叠时标题写要你处理的数。 好：改动最小，从现在的结构长出来。 代价：本机列表长时把远程挤到下面，只能靠标题吸底提醒；要扫几个区。

三个方向共用：连接状态

不管选哪个都要的部分 mac-mini 和它的会话只是示意。断开的文案来自现有的 Link::Offline 和 1～30 秒重连。 版本旧的提示 spec 里写着还没设计，这里是第一稿。 三个方向都要：卡片加更新时间，行上显示空间名，⌘J 跨机器跳，标题用配置里的名字。
