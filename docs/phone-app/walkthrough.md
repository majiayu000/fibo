# 手机全量走查清单

**要支撑的决定：** 这次改动能不能说「手机上做完了」。只走改到的那一块不够：换 App、合进别人的 PR 之后，没改到的页面也可能坏（见 [real-device-findings.md](real-device-findings.md)）。

**规则：** 下面三种时候都要把整张表走一遍。每一项要么有截图并写「过 / 不过」，要么写明为什么跳过。报告里没走的项会自动列成「没验」。

- 改了手机能看到或能操作的东西，说做完之前。
- 换了电脑 App 或手机 App 之后。
- 更新插件之后。

**工具：** `scripts/phone-walk.py`，做法见 `.claude/skills/phone-walk/SKILL.md`。截图和报告放在 `~/Documents/claude-pages/mooring/<日期>-phone-walk/`，不进仓库，因为里面可能有私人内容。

## 安全

- 只打开测试会话。测试会话用深链直接进（`phone-walk.py open-chat`），不在首页点卡片：首页的顺序会变，点卡片容易点进真实会话。
- 「允许 / 拒绝 / 停下 / 发送」这类会改变事情的按钮，要用 `phone-walk.py tap` 来按。屏幕上没有测试标记 `phone-walk` 时，它拒绝按。
- 标「只看」的项不按任何按钮，看完就返回。
- 「移除电脑」「重新扫码配对」「换机器码」永远不按。
- 「以后都允许」不按。
