# Mooring 手机首页竞品调研（2026-11-07）

**结论：同类的首页基本都是一张排好序的会话列表，读过首页的 7 家里没有一家用数字格做概览（另外 3 家的文档没写布局）。** 所以「主页」要做，但不用做成仪表盘；我上次画的方向 A 应该去掉数字格，改成要你决定的卡片加可折叠的分组。

最值得补的是：额度一行、搜索、划掉后撤销，然后是推送。详细见 [建议](02-my-plan.md) 和 [竞品证据](01-competitor-research.md)。
