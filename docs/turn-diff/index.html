放弃条件

真实会话里，如果超过三分之一的文件只有行数、取不到内容，这个方案就撤回。11-06 用本机记录量过，没有触发：Claude 最近 400 个记录的 2525 次编辑都带内容，Codex 最近 150 个记录里 171 个被改的路径有 165 个带内容。1951 个 Claude 文件里 8 个因为中途被格式化工具等改过而退回按次显示。这些是开发者本机的数字，其他 Agent 没接入，会显示「只有行数」。
