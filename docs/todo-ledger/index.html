    我建议这样改

    不新建功能，把现有待办改成“会跟进的事项”：你只写一句话，Agent 负责补充和写进展，只有你能标完成。代码里“开始”已经会把待办内容交给 Agent，缺的是 Agent 写回和界面上看得到进展。

    改什么现在改成
    Agent 写回mooring 没有待办命令加 mooring todo add/show/note/list，没有 done
    记录填表单，或从会话“放入待办”看板上写一句回车；或在会话里说“记一下”
    详情说明、验收标准、证据你写的 / Agent 补充 / 进展时间线，分开显示
    再开会话只带标题、描述、验收标准再带上背景和进展，接着做
    时间待办没有时间字段加创建和完成时间，才能分“今天”和“之前”
    状态7 种，如“会话都做完了”“验收齐了”待办只显示 没做 / 在做 / 做完了，会话状态不变
    看板卡片开始后就只看到会话卡ToDo 卡跟着会话走，几个会话合成一张
    标完成待办和会话要各标一次标 ToDo 时关联会话一起完成，可撤销

    A 和 B 怎么选

    A 看板里跟进（我推荐先做）：不加新页面，你已经习惯看鸟瞰，切“只看 ToDo”就只剩要完成的事。坏处是默认视图里 ToDo 和会话卡混在一起。

    B 单独清单：按“今天新增 / 之前没做完 / 今天做完”排，每天要做什么最清楚，也最接近你说的“账本”。代价是多一个页面，事情和会话要到两处看。

    这版不做

    优先级、负责人、标签、周期、飞书自动捡取、全局快捷键。用两周后，记录或启动的事少于 10 件，或进展你根本不看，就不再加功能。

    Demo 里的事项和 Agent 写回内容都是示例，终端是模拟的，没有接真实数据。
