# 记进 Fibo 待办

1. 先运行 `fibo todo list`，看是不是已经有这件事。
2. 已经有：`fibo todo note --task <编号> "补充的内容"`。
3. 没有：`fibo todo add "一句话标题" --said "用户原话"`。报错说要指定空间时，加 `--space <空间>`，错误里有可选的空间。

记完用一句话告诉用户记了什么。

完成由用户在 Fibo 窗口里标记，你不能标。

`fibo` 找不到或连不上时，告诉用户没记上和报错内容。不要绕过命令，直接写 Fibo 的 socket 或数据库。
