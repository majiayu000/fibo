# 记进 Fibo 待办

1. 先运行 `fibo todo list`，看是不是已经有这件事。
2. 已经有：`fibo todo note --task <编号> "补充的内容"`。
3. 没有：`fibo todo add "一句话标题" --said "用户原话" --done-when "什么算做完"`。报错说要指定空间时，加 `--space <空间>`，错误里有可选的空间。记下后当场就开始做的，加 `--work`。

不记：当场问完答完的事、决定不做或「先都留着」这类决定、只有一个链接没有要做什么的。

记完用一句话告诉用户记了什么。

做完了：`fibo todo note --done --task <编号> "证据：PR、提交、跑过的检查"`。待办会显示「等你确认」，由用户在窗口或手机上确认或退回，你不能标完成。

`fibo` 找不到或连不上时，告诉用户没记上和报错内容。不要绕过命令，直接写 Fibo 的 socket 或数据库。
